中国象棋 · 使用教程

一份简单明了的上手说明，照着做就能玩。

一、第一次打开

  • 首次启动会弹出注册/激活窗口。按提示完成激活（扫码或输入激活码）即可进入主界面。
  • 软件运行时屏幕会保持常亮，不会自动熄屏。

二、选择对战模式

右上角的模式按钮（图标形式）点一下，会弹出四种模式：

模式说明
双人对战同一部手机上两个人轮流下
玩家执红你执红方，电脑执黑
玩家执黑你执黑方，电脑执红
双机对战红黑都由电脑下，你坐旁边看

切换模式不会清空棋盘，会从当前局面继续。

三、怎么下棋

  1. 点一下要走的棋子，会高亮显示它能走的位置。
  2. 再点一下目标位置，棋子就走过去了。
  3. 走法不合法（比如送将、对面将脸对脸）会提示，不会生效。
  4. 轮到谁走，底部状态栏会标明。被将军时会弹出"将军"提示。

四、常用按钮

  • 新局：开一局全新的棋（会确认是否清除当前进度）。
  • 悔棋：退回到上一步。
  • 翻转：把棋盘上下翻转，方便对面的人看。
  • 上一步 / 下一步：一步步回看刚才的走法。
  • 支招：让电脑给你出主意，给出几步好棋和评分。
    • 电脑正在思考时，这个按钮会变成"中断"，点它可以让电脑停手。
  • 设置：调整电脑强弱、思考时间、强制变着、音效等（详见第五项）。

五、软件设置的解释

点设置按钮打开设置面板，各项含义如下：

  • 电脑棋力（技能级别 1–20 级）：数值越大电脑越强。新手先调低，想认真研究就往高拉；最高 20 级基本是满血状态。
  • 思考时间（1–60 秒）：电脑每走一步允许花费的时间。时间越长、算得越深，但也越慢；设得过高（超过 15 秒）软件会提醒注意手机性能，避免卡死。
  • 搜索深度（5–120 层）：引擎向前推算的层数，越大越强越慢。一般配合思考时间一起调即可。
  • 支招变化数（MultiPV 1–5）：点"支招"时，除了给出最佳着法，还会同时列出几个候选变化方便对比。设为 1 只给一手；≥2 时每多一条变线要额外花搜索时间（软件会提示建议的思考时间）。
  • 强制变着（开 / 关）：遇到长将、长捉、三次重复局面时，自动要求必须变着，符合正式比赛规则；关闭后则只提示、不强制。建议保持开启。
  • 背景音乐（开 / 关）。
  • 音效（开 / 关）：走子、吃子、将军等操作的提示音。
所有设置会自动保存，下次打开软件仍然生效；改完点"确定"即可，对当前和之后的对局都有效。

六、拍照 / 相册识谱（最省事的功能）

看到书上的残局、网上的棋图，不用手动摆：

  1. 先点摆棋进入摆棋模式。
  2. 摆棋面板下方有三个按钮：清空棋盘 / 拍照 / 图片。
    • 拍照：直接拍一张棋盘照片。
    • 图片：从相册里选一张棋图。
  3. 软件会自动识别棋盘和棋子，并摆好，连子都不用你动手。
  4. 摆好后退出摆棋模式即可从当前局面开始下。
提示：照片尽量拍正、光线好，识别更准。

相关设置说明（识谱相关）

  • 相机权限：首次点"拍照"会请求相机权限，请允许；若不想授权，可改用"图片"从相册选图。
  • 识别引擎：棋盘识别（ONNX 模型）在软件启动后自动在后台加载，无需手动开启。若提示"识别服务未就绪"，稍等几秒再试即可。
  • 识别不是必须：即便识别失败或不准，也可点"清空棋盘"手动摆放，不影响正常对局。
  • 电脑棋力、思考时间、强制变着等对局设置见第五项《软件设置的解释》。

七、自由摆棋

自由摆棋可以自己摆出想研究的残局、排局，再开始对弈或复盘。

进入摆棋模式

  • 点底部 摆棋 按钮进入摆棋模式。此时该按钮变为 "完成"，其它按钮暂时禁用，屏幕下方出现"选择棋子"面板。

摆放棋子

  1. 在"选择棋子"面板里点一下要摆的棋子（黑棋一行、红棋一行，每种棋子按剩余数量显示）。
  2. 再点棋盘上任意一格，棋子就放上去。
  3. 想移动已摆好的棋子：先点棋盘上的棋子选中它，再点目标格即可移动或覆盖。
  4. 想拿走某颗棋子：选中它后，再点 原位置 即可下架（将/帅也能移除）。

摆棋规则（较为宽松）

  • 将 / 帅：只能放在九宫格内。
  • 士：只能放在九宫格内的斜线点。
  • 象 / 相：只能放在己方半场（不能过河）。
  • 马、车、炮、卒 / 兵：可摆放在任意合法格。
  • 数量上限：将/帅每方 1 个；士、象、马、车、炮每方 2 个；卒/兵每方 5 个，超过数量放不上去。

面板下方辅助按钮

  • 清空棋盘：一键移除除将/帅外的所有棋子，方便重摆。
  • 拍照 / 图片：识别棋盘照片或相册图片并自动摆好（详见第六项）。

完成并开始

  1. 双方都摆好将/帅后，再次点 "完成" 按钮。
  2. 若缺少某方将/帅，会提示"摆棋未完成"，请补齐后再点完成。
  3. 双方齐全后弹出 选择开局方 对话框：选"红方开始"或"黑方开始"。
    • 若你选的先行方不走、而对方正被将军，会提醒"被将方须先应对"，可重新选择。
    • 若双方帅/将同时被将，局面非法，需先调整棋子。
  4. 确认后退出摆棋模式，默认进入 双人对战，从你摆好的局面开始下；之后可随时用右上角模式按钮切换成人机或双机。

小提示

  • 摆棋过程中可随时点"拍照/图片"把书上的棋图识别进来，再手工微调。
  • 摆好的局面会作为新开一局，之前加载的棋谱 / 回放状态会被清空。

八、棋谱的保存与回看

  • 保存：把当前这盘棋存成棋谱文件，随时能找回。
  • 加载：打开棋谱列表，选一局加载进来继续下或复盘。
  • 加载后可以用"上一步 / 下一步"慢慢回放，研究哪步妙、哪步臭。
  • 加载的棋谱里，你也可以手动接管继续往下走。

九、评分曲线

对局过程中底部会有一条评分曲线，把整盘棋谁占优势画得清清楚楚，红高黑低一眼可见，方便复盘。

十、结束一局

  • 将死 / 困毙会直接判负。
  • 出现三次重复、长将、长捉等，会提示和棋或变着；需要认输时也有相应确认。
  • 想重新开始，点新局即可。
就这么简单：选模式 → 点子走子 → 卡壳点支招 → 想研究用拍照识谱或摆棋 → 下完保存复盘。祝你玩得开心！
